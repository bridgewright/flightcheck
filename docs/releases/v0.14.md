# flightcheck v0.14.0

Released: 2026-08-13

The closed beta gets its door key, navigation stops teleporting, the
interviewer starts acting like one, the product moves to its own
address, and three of the repo's own review findings are paid off —
including a gate that now reads what code says instead of how it
spells it.

Disclosure carried from the changelog, so the numbers stay honest:
flightcheck still has no external users at this tag. The closed
beta's shared access code ships in this release, minted and live, but
it has not yet been distributed; every session behind this release's
claims was run by the operator. When beta participants arrive, their
sessions count as real usage and their packages are counted as what
they are — non-revenue.

## What shipped

**A closed beta on one shared code** (F-87, DECISIONS 062). Sign in,
enter the code once, and the account's next three JD registrations
are born unlocked — six scored sessions each, no payment, every
package expiring on the beta's fixed end date. The grant rides the
existing comp machinery, so nothing that counts revenue can see it;
the code is stored only as a normalized hash with a redemption cap
and a kill switch; the entitlement counter survives package deletion
by design.

**Motion and continuity** (F-88, DECISIONS 063). Route changes
dissolve in over 0.3 seconds while the chrome holds still; the
landing's hero cloud drifts a twentieth behind the scroll. Opacity
and transform only, no new dependency, reduced motion lands on the
settled state instantly — pinned in the suite. The session room is
deliberately excluded.

**The interviewer acts like one** (F-75, DECISIONS 064). Company-
aware commentary grounded in what the rubric actually carries and
nothing else, reactions that engage the substance of the last answer,
a wrap-up whose register reflects how the interview actually went,
and adaptive warmth past the midpoint when the candidate has clearly
been strong. The one line never crossed: adaptivity changes WHAT is
said, never WHEN the session ends.

**flightcheck.coach** (F-79 first half, DECISIONS 065). One constant
flipped and every canonical surface followed; the old address
redirects path-preserving; the auth allowlist learned the new origin
before the flip; Search Console is verified with the sitemap
submitted. Historical records keep the address they shipped with.

**The hardening trio** (F-85/F-86/F-89, DECISIONS 066–068). Fallback
interview questions read like an interviewer wrote them, pinned
against the committed real rubric's sentences rather than tidy
fixtures. A quick interview's ending no longer probes a recording
that cannot exist, so the storage error log means something again.
And the design-token gate gains a cooked-string pass: files are
parsed with the TypeScript compiler, constant concatenations folded,
escapes and JSX character references resolved, and a two-dozen-entry
evasion corpus is the contract the gate must keep catching to pass
its own suite.

## The process, honestly

Every batch in this tag ran two adversarial review rounds, and in
every track the second round found something in the first round's own
work: a whitespace fix that broke the contract it was defending, a
gate whose corpus proved a private copy of the rules, an anti-evasion
scan blind to the HTML entities the product's own house style writes
every day. Three of four prescribed weaken-the-scan mutations
survived the first delivered version of the F-89 gate. The pattern —
a fix is written fast, by an agent just proven wrong, under the
impression the problem is now understood — has held for six
consecutive releases, and it is why round two exists.
