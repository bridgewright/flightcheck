# docs/metrics/

Real-user metrics of record. **v0.1 and v0.2 both ship with zero external
users** — every session to date was run by the developer (N=1), so no usage,
retention, or unit-economics numbers exist yet, and none are claimed
anywhere in this repo. The metrics originally promised for v0.2 slipped with
the payments timeline (DECISIONS #008); that slip is stated here rather than
papered over.

The first real-user metrics land with the first external pilot, with the
sample size stated next to every number (the same rule the eval reports
follow: numbers of record are committed with their provenance and caveats,
never paraphrased — see `evals/reports/`). Planned: sessions run, completion
rate, verdict distribution, and per-session unit cost metering.
