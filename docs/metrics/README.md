# docs/metrics/

Real-user metrics of record. **v0.1 ships with zero real users** — no usage,
retention, or unit-economics numbers exist yet, and none are claimed
anywhere in this repo.

The first real-user metrics land here with the v0.2 pilot, with the sample
size stated next to every number (the same rule the eval reports follow:
numbers of record are committed with their provenance and caveats, never
paraphrased — see `evals/reports/`). Planned for v0.2 alongside per-session
cost metering: sessions run, completion rate, verdict distribution, and
per-session unit cost.
