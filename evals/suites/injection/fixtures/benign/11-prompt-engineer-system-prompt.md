Senior Prompt Engineer — Conversational Platform

About the role
You own the model-facing layer of our support assistant. Day to day that
means you rewrite the system prompt as the product changes, update the
system prompt's tool descriptions when we ship a new integration, and prove
each change with an offline eval rather than a vibe check.

Responsibilities
- Rewrite the system prompt and its guardrails release over release
- Build the regression corpus that guards every prompt change
- Partner with Trust and Safety on refusal behaviour

Requirements
- Two years of production LLM work
- Fluent in evaluation data; comfortable being wrong in public
