# Release gate — v0.10.0 (2026-08-05)

Two runs. The first failed, and that is the story worth keeping.

This tag changes the content judge for the first time since the gate has
existed: the judge now authors a per-dimension key span and the
strengths/weaknesses lists (F-48, F-03b). The gate is the only live exercise
those prompt and response-schema changes get before production, and it did
its job.

## Run 1 — FAIL (exit 1)

| Suite | Result | Baseline |
| --- | --- | --- |
| `rubric_discrimination` | accuracy **0.67** (2/3) — FAIL | 0.8 |
| `delivery_discrimination` | judge accuracy 1.0, DSP 2/2 | 0.8 |
| `injection_defence` | recall 1.0, FP 0.0 | 0.9 / 0.0 |

The failing triplet (`ai-evaluation-responsible-ai-1`, 3/3 at the v0.9.0
gate) scored strong 4.7, borderline **4.7**, weak 1.0: not an inversion, a
tie at the top. The weak answer stayed decisively separated; the borderline
answer was over-scored. The one variable since the passing run is the judge
change, and the mechanism reads directly out of the added rules: mandating
"1-3 strengths" per dimension puts the judge in a positive-finding frame
while it scores, and a borderline answer with listable strengths drifted up.

## The fix

Two rule changes, committed before the second run: the score is fixed by the
anchors BEFORE the authored fields are written and cannot be moved by them
("an answer the middle anchor describes is still a middle-anchor answer
however many strengths it has"), and both lists allow zero items so nothing
is invented for weak answers.

## Run 2 — PASS (exit 0)

| Suite | Result | Baseline | N |
| --- | --- | --- | --- |
| `rubric_discrimination` | accuracy **1.0** | 0.8 | 3 triplets |
| `delivery_discrimination` | judge accuracy **1.0**, DSP 2/2 | 0.8 | 2 triplets |
| `injection_defence` | hostile recall **1.0**, benign FP **0.0** | 0.9 / 0.0 | 13 hostile, 16 benign |

The second run also proves what no fake-client test could: the enlarged
response schema (nullable `key_span` rides `response_json_schema` as anyOf)
is accepted live by the model API, which both review rounds had flagged as
this batch's blind seam.

The sample sizes are small and are stated as small; three triplets cannot
distinguish a judge that is right from a judge that is lucky, and a 2/3 fail
can be noise as easily as signal. What the failure produced is still worth
having: a plausible mechanism, a rule change that removes a real fabrication
pressure, and a passing run on the exact prompt that ships. F-05 (golden set
3 to 9 triplets) remains the card that makes this gate statistically honest.
