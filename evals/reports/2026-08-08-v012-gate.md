## What this run does and does not say

- It says the scoring stack — compiler, judges, injection classifier,
  faithfulness contract — is unchanged in measured behavior across a
  release that deliberately did not touch it. The release's risk lived
  in the web app and the session planner; the gate confirms the blast
  radius stayed there.
- It does not cover the naturalness work: `morgan_naturalness` remains
  report-only by DECISIONS 047 and is not part of this gate. Its bar
  is still being defined (bar.md v1, worklog Round 1); its numbers
  join a gate only after the bar survives cycles unchanged.
- It does not cover the two behavior changes this release made to the
  live session (the 0.6 s debounce cut and the closing auto-end,
  DECISIONS 055-056). Those are pinned by the web test suite's
  adversarial and SSOT gates, not by these suites — recorded here so
  a reader does not mistake a green scoring gate for evidence about
  turn-taking.

Same caveat as every prior report: N is small and says so. The gate is
a tripwire against regression, not a large-sample accuracy claim.
