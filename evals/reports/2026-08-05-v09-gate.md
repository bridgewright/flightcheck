# Release gate — v0.9.0 (2026-08-05)

One run, one tag. Command: `cd services/scorer && uv run scorer-evals`, exit **0**.

| Suite | Result | Baseline | N |
| --- | --- | --- | --- |
| `rubric_discrimination` | accuracy **1.0** | 0.8 | 3 triplets |
| `delivery_discrimination` | judge accuracy **1.0**, DSP 2/2 | 0.8 | 2 triplets |
| `injection_defence` | hostile recall **1.0**, benign false positives **0.0** | 0.9 recall, 0.0 FP ceiling | 13 hostile, 16 benign |

The sample sizes are small and are stated as small. Three triplets and two
triplets cannot distinguish a judge that is right from a judge that is lucky;
what they can do is fail loudly when a change breaks discrimination outright,
which is what a release gate is for. F-05 (golden set 3 to 9 triplets) is the
card that fixes the sample size, and it is still open.

This release changed no scoring code. The v0.9 batch was web-only (a
walkthrough helper, the package identity, menu dismissal); the suites ran
because the rule is that they run before a tag, not because a scoring change
asked for them.
